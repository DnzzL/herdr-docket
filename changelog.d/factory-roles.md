- **`init` writes the dev and reviewer methods as roles.** A `dev` or
  `reviewer` agent is a few lines — which repo, what is at stake — and names
  `roles/dev.md` or `roles/reviewer.md`, where the method lives: scope, the
  least code that works, test first, proof over claims, the PR a stranger can
  judge. A second project's dev is one short file naming the same role; an
  existing role is never overwritten.
