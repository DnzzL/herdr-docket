- **`init` writes the dev and reviewer methods as roles.** A `dev` or
  `reviewer` agent is a few lines — which repo, what is at stake — and names
  `roles/dev.md` or `roles/reviewer.md`, where the method lives: the procedure for
  a card and the PR a stranger can judge. How to write the code it defers to
  the engineering skills and the repo's AGENTS.md. A second project's dev is
  one short file naming the same role; an existing role is never overwritten.
