- **`init --factory` writes the dev and reviewer methods as roles.** The
  `dev` and `reviewer` agents it installs are a few lines each — which repo,
  what is at stake — and name `roles/dev.md` and `roles/reviewer.md`, where
  the method lives: scope, the least code that works, test first, proof over
  claims, the PR a stranger can judge. A second project's dev is one short
  file naming the same role; an existing role is never overwritten.
