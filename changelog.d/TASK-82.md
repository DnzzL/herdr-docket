- **The docs say which ideas get a grill and which get a card.** *How it works*
  and the README used to describe only the spec path, so an idea with a clear
  outcome looked like it had to go through a grill. Both now name the two
  paths and the condition that picks one: unclear goes grill → spec →
  tickets → a card with a `Spec:` line; clear goes straight to a card with
  its own *Done when* / *Verify by*.
